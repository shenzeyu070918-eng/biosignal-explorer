# BioSignal Explorer

BioSignal Explorer is a small learning project for students beginning to study ECG and physiological signals. Its goal is to help a student connect a two-column `time` / `voltage` CSV with an ECG waveform and five basic signal values: Duration, Sampling Rate, Maximum, Minimum, and Mean.

**Current status:** Project scope, phased plan, logs, and a minimal source placeholder exist. The application has not been implemented. Phase 1 is awaiting student review and acceptance.

**Future running method:** A local run method will be chosen and documented during Phase 1, before application code is added. There is no run command yet. The intended user flow is to open the website, import an ECG CSV, and inspect the waveform and basic information.

See `PROJECT_SCOPE.md` for scope and `PLAN.md` for phase gates.
